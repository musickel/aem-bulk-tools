AEM Bulk Tools — User Guide & Documentation

v1.7.0

⚙️ Profile & Authentication

Configure target AEM author environments using supported authentication methods:

  1. Cookie Session: Uses active cookies from an open tab in your target host.
  2. Auto IMS Bearer Token: Intercepts active IMS tokens automatically on AEM Cloud Service instances.
  3. Basic Auth / Static Token: Store credentials or static Bearer tokens encrypted locally.
Encrypted Backup: Use the Backup tab to export/restore AES-256 encrypted configuration bundles.

📄 Content Fragment Manager

Bulk import/upsert Content Fragments from CSV/XLSX or extract existing fragments to JSON.

  1. Ensure spreadsheet contains required columns: path, name, title, model. Remaining columns represent fragment element fields.
  2. Set a delay between rows to regulate processing speed.

🚚 Asset Mover & Renamer

Batch move or rename assets in the JCR tree.

  1. Upload a CSV/XLSX file with Column A as the current path and Column B as the target destination path.
  2. Source and target file extensions must match.

📦 Package Builder

Build CRX packages with optional size-based package splitting.

  1. Provide target JCR paths in Include Paths.
  2. Enable Split Package by Size Limit to automatically partition assets under a specified MB cap.
Missing paths (HTTP 404) are automatically flagged in red in the console and excluded from package definitions.

🚀 Bulk Publisher

Activate or Deactivate pages and assets across AEM instances.

  1. Select Activate or Deactivate.
  2. Input paths manually or upload a spreadsheet.
  3. Enable Include Children to trigger tree activation.

📊 Remote Google Sheet Audit Logging

Every execution run automatically posts an audit log entry to your Google Spreadsheet:

  • Column A: Authenticated Google Chrome Email, AEM Session ID, and External IP address.
  • Column B: Full console execution log summary.
